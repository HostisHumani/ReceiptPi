# ReceiptPi documentation

*[Deutsche Version](README.de.md)*

ReceiptPi turns a Raspberry Pi and a receipt printer into a small
household printer: shopping lists, to-dos, notes, weather, guest Wi-Fi
slips and more, printed from your phone or automatically.

Every page explains one thing: what it does, how to use it step by step,
and what to do if it doesn't work.
