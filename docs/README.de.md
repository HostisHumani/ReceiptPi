# ReceiptPi-Dokumentation

*[English version](README.md)*

ReceiptPi macht aus einem Raspberry Pi und einem Bondrucker einen kleinen
Haushaltsdrucker: Einkaufszettel, To-dos, Notizen, Wetter, Zettel fürs
Gäste-WLAN und mehr, gedruckt vom Handy aus oder ganz automatisch.

Jede Seite erklärt genau eine Sache: was sie kann, wie du sie Schritt für
Schritt benutzt und was du tun kannst, wenn es nicht klappt.
